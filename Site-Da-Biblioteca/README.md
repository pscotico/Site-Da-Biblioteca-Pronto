# Biblioteca Bar

Projeto de site/cardápio do Biblioteca Bar, desenvolvido com HTML, CSS e Tailwind CSS.

## Requisitos

- Node.js e npm instalados

## Como executar

1. Clone ou baixe este repositório.
2. No terminal, entre na pasta do projeto.
3. Instale as dependências:

   ```bash
   npm install
   ```

4. Para recompilar o CSS do Tailwind em modo de desenvolvimento:

   ```bash
   npm run dev
   ```

5. Abra `cardapio.html` no navegador.

> O arquivo `styles/output.css` é mantido no repositório porque o HTML o utiliza diretamente. O projeto também contém `Untitled-1.html` e arquivos na pasta `juan-codigos`, preservados para não excluir versões ou recursos que possam ser úteis.
